### ✨ Features
- 🎮 **Interactive Gameplay:** Smooth and fast game logic against the computer.
- 📱 **Fully Responsive:** Works perfectly on Mobile, Tablet, and Desktop.
- 🎨 **Modern UI:** Clean design with cool hand icons and animations.
- ⚡ **Lightweight:** No frameworks, just pure Vanilla JS.
- 🏆 **Live Score Tracking**

### 🛠️ Tech Stack
- **HTML5** - Structure
- **CSS3** - Styling & Animations
- **JavaScript (ES6)** - Game Logic
- **GitHub Pages** - Deployment
